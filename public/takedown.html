Takedown requests

Last updated 6 November 2026

You can ask for a file to be removed if you own it, if you uploaded it and changed your mind, or if it should not be public.

How to ask

  • Send a message through the feedback form on the site.
  • Give the file title and course code.
  • If you uploaded it, add your ticket number.
  • Say why it should be removed and, if you own it, how we can tell.

What happens next

  • An administrator reviews the request.
  • If it is valid, the file is removed from the library and deleted from storage.
  • Download counts for that file are removed with it.
